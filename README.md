# COORDY
A Discord.JS V14.25.1 BOT

## Environment Variables
To run this project, you will need to add the following environment variables to your .env file

### BOT TOKEN
TOKEN=

### BOT CLIENT_ID
CLIENT_ID=

### BOT GUILD_ID
GUILD_ID=

### ADMIN USER ID
ADMIN_ID=

### TEMPORARY VOICE CREATOR ID
TEMP_CREATOR_ID=

### TEMPORARY VOICE CATEGORY ID
TEMP_CATEGORY_ID=
